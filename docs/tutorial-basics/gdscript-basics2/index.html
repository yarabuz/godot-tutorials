Mathematical Shorthand Operators​

GDScript supports standard augmented assignment operators.
These mathematical shorthand operators let you modify a variable's value and assign it back in a single step.

  • Increment +=
var coins : int = 0

coins = coins + 15
# or
coins += 15

  • Decrement -=
var potions : int = 0

potions = potions - 1
# or
potions -= 1

  • Multiplication *=
var score : int = 0

score = score * 2
# or
score += 2

  • Division /=
var width : int = 0

width = width / 2
# or
width /= 2

  • Modulus(Remainder) %=
var current_weapon : int = 0

# if it reaches 5, your modulus is 5, automatic restart

current_weapon = current_weapon % 5
# or
current_weapon %= 5

  • Exponentiation **=
var experience : float = 0

# The requirement increases in a curved fashion, becoming more difficult

experience = pow(experience, 1.2)
# or
experience **= 1.2

Conditional operators:​



Conditional operators controls the flow of the code. It determine where to continue next.


There are a couple of reserved keywords to add to our dictionary:

  • IF
    • if condition_to_evalute:
  • ELSE
    • else:
  • ELIF
    • elif another_contion:

IF​

New structure: The reserved keyword IF, followed by any boolean statement and a colon.
This creates a new block of code marked by a new indent segment, and everything you put inside this block will only execute if the preceding boolean statement is true.
Otherwise, it will be ignored, and pretend as if it doesn't exist.



ELSE​

Introducing the Else statement.
This is the new structure to remember:
the reserved keyword “else” followed only by a colon, a new line with a new ident segment.
“Else” can not be declared alone, it should be preceded by an “If” statement and in the same level of indentation.
The “If” statement could be alone but not in the case of the “Else” statement.

    if distance_to_bed < 3:
        pass
    else:
        print("You may not rest now, the bed is too far away")

Here the reserved keyword "pass" doesn't nothing other than tell to the compiler that it is OK close the block of code created for this "If" statement without any content, "just bare wih me".


Nesting IFs​

Inside the first "If" statement we can "nest" a new "If" statement asking if is it nigh time?
And if is not, show the message: "You can sleep only at night"

    if distance_to_bed < 3:
        if  is_night_time:
            print("Sweet dreams!")
        else:
            printraw("You can sleep only at night ")
            print("or during thunderstorms")
    else:
        print("You may not rest now, the bed is too far away")

Here the method printraw what it does is printing to the console without creating a new line, so in the next line of code we can make another printing and write the rest of the message.

ELIF​

But what if you want to chain differents conditions in a row?
Just for that we can use another reserved keyword "elif"

Elif has the peculiarity of only being check if the previous checking was a false statement.
In other words, if you know that is night time already, there is no need to check for the weather.
and also "elif" can not be alone, because is like a second or third condition.
Same case as "Else" is the otherwise and second or third condition and requires a starting point.

    if distance_to_bed < 3:
        if  is_night_time:
            print("Sweet dreams!")
        elif is_weather_thunder:
            print("Sweet Dreams")
        elif are_monster_nearby:
            print("You may not rest now, there are monsters nearby")
        else:
            printraw("You can sleep only at night ")
            print("or during thunderstorms")
    else:
        print("You may not rest now, the bed is too far away")

Logical operators:​


In Godot's GDScript, logical operators evaluate Boolean conditions to manage game logic flow.
You can use it simbol form or word form.

  • AND
    • && and
  • OR
    • || or
  • NOT
    • ! not

What these word made is conect to condition together and create a new boolean value following a couple a rules, known as truth tables.

for AND all values needs to be true for the output to be true. if any is false, the output is false
For OR any value needs to be true in order to the output to be true, with just one, we no care about the rest of condition.
NOT simply change a condition from true to false or the other way around.

AND (&&)​

For example we could ask a question if is_night_time and also and at the same time you are less than 2 blocks away from the bed, you could procced to sleep.

    if is_night_time and distance_to_bed < 3:
        print("Sweet Dreams")
    else:
        print("You can sleep only at night")
        print("You may not rest now, the bed is too far away")

In this case both conditions needs to be true in order to have a sweet dreams but if is not night time or you are too far away from your bed or both conditions are false then the entire if statement if false and therfore we go to the else statement.

OR (||)​

Now can check at the same time if it is night time or if the weather is thunderstorm in order to allow the player to sleep.

    if distance_to_bed < 3:
        if  is_night_time or is_weather_thunder:
            print("Sweet Dreams")
        elif are_monster_nearby:
            print("You may not rest now, there are monsters nearby")
        else:
            printraw("You can sleep only at night ")
            print("or during thunderstorms")
    else:
        print("You may not rest now, the bed is too far away")

NOT (!)​

We cann another If statement, just below the first one. this one will act as a separate check, no matter what happen before it start all over again.
we have a boolean var called is_spawn_point_set and it will act as a flag, intially is false so we need to negate this one with a not operator.
Then inmediatily change to true so it will enter the first unless other parts of the code changes this value again.

    if distance_to_bed < 2:
        if  is_night_time or is_weather_thunder:
            print("Sweet Dreams")
        elif are_monster_nearby:
            print("You may not rest now, there are monsters nearby")
        else:
            print("You can sleep only at night")
    else:
        print("You may not rest now, the bed is too far away")

    if not is_spawn_point_set:
        spawn_point_set = true
        print("Spawn point set")

Warnings:​

You could add as much IFElifElse statement as you need but be aware that adding too much checkers, especially nesting ifs, it will dificult the reading of the code.

For example, if you have to check every single time a condition alongside the rest, you could extract that condition as a common factor and then negate it to execute its behavoir.

    if is_in_overworld and distance_to_bed < 2:
        if  is_night_time or is_weather_thunder:
            print("Sweet Dreams")
        elif are_monster_nearby:
            print("You may not rest now, there are monsters nearby")
        else:
            print("You can sleep only at night")
    else:
        if is_in_overworld:
        print("Died by Intentional Game Design")
        else:
            print("You may not rest now, the bed is too far away")
    
    if not is_spawn_point_set:
        is_spawn_point_set = true
        print("Spawn point set")
    if not is_in_overworld:
        print("Died by Intentional Game Design")

        if  is_night_time or is_weather_thunder:
            print("Sweet Dreams")
        elif are_monster_nearby:

        else:
            print("You can sleep only at night")
    else:
